# RugMaps

> **NOTE: This repo is orphaned and on a merge-and-archive track into [rmi-backend](https://github.com/RugMunchMedia/rmi-backend). See [TRIAGE.md](TRIAGE.md).**

Entity relationship mapping and cluster visualization for crypto wallet
forensics. Originally part of the Rug Munch Intelligence platform.
This code exists to preserve history during migration.

## Quick Start

This repo is on a merge-and-archive track — there is no standalone runtime.
The entity mapping code is being migrated into [rmi-backend](https://github.com/RugMunchMedia/rmi-backend).

```bash
# Browse the code
git clone https://github.com/RugMunchMedia/rugmaps.git
cd rugmaps
# See TRIAGE.md for the merge plan
```
